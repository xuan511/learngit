# 使用说明

## 工作台

首页搜索覆盖截图 OCR、剪贴板、笔记、PDF 提取文字与常用片段。左侧切换内容范围；“查看全部”恢复统一视图。顶部“添加内容”可以新建笔记、片段，或导入图片 / PDF / 本地文件。空列表给出开始方法，不预置虚假历史。

## 截图与识别

按 `Ctrl+Alt+A` 或点“快速截图”，在任一显示器拖出矩形并松开，截图自动保存，默认进入后台识别队列。Esc 或右键取消。跨不同缩放显示器不拼接选区，请在单个显示器内框选；托盘“截取指定显示器”可限定屏幕。

预览上方可复制、另存 PNG / JPG、重新识别、添加笔记、收藏或关闭。下方选择矩形 / 箭头 / 画笔 / 文字 / 马赛克后在图片上拖动（文字点按输入）。可撤销与重做，点击“另存标注副本”保存修改，原图不会丢失；需分享打码图时复制或导出当前已标注图片。再次截图会关闭旧预览以释放内存，原图已自动保存，请先保存需要保留的标注副本。

识别结果会自动显示在截图预览右侧，可直接复制，不必关闭预览或再点识别。在截图库选中记录，正文可修改、自动保存；“OCR 原文”只读并保留本次引擎原始输出。重新 OCR 会刷新原始结果，但不会覆盖手工修正文。“识别本页未处理图片”处理当前页最多 60 条，不遍历所有历史。

OCR 可能混淆字母 O 和数字 0，不会擅自改写代码或地址。重要数值请核对原图。空白图片会明确提示未识别到文字。

## 剪贴板

复制文本、代码、网页、图片或本地文件列表后自动入库。同内容去重并更新时间；应用自身复制使用独立 MIME 标记避免重复记录。HTML 同时保留可检索纯文本和原始格式，再复制时恢复两种格式。文件列表再复制时保留文件 MIME，可在资源管理器手工粘贴。

`Ctrl+Alt+V` 打开快捷面板，输入查询，↑ / ↓ 选择，Enter 复制，Esc 关闭；单击条目也会复制。条目右键提供置顶、收藏和删除。为避免焦点错误，不自动往其他应用发送粘贴按键。

托盘可立即暂停 / 恢复监控。设置中可调整保留天数、普通历史条数、单条大小、图片历史和前台应用黑名单。图片上限按解码内存大小计算。收藏、置顶、已关联笔记的记录不会自动清理；“清空普通剪贴板历史”同样保留这些内容。单条私密记录可在详情中删除。

## 搜索与笔记

按 `Ctrl+Alt+F` 或 `Ctrl+K` 定位搜索框。中文、单汉字、英文和 `0x09F0` / `09F` 均可查询。多个词用空格分隔；可以筛选类型、逗号分隔的标签、收藏以及起止日期（YYYY-MM-DD）。英文零精确命中时可能给出标记为“近似匹配”的结果，范围有限，不承诺全库模糊召回。

“添加内容 → 新建 Markdown 笔记”支持正文、代码块、托管图片相对路径与 Markdown 预览，停止输入 650 毫秒后自动保存，切换内容时也会保存。远程图片不加载。片段用名称作为标题、分类作为标签，复制正文即可复用。

图片“存为笔记”会带入正文、图片 Markdown 和数据库关联。“关联内容”搜索截图、PDF 或其他记录，双击选择；PDF 可填页码。详情双击关联项跳转到该内容，右键移除关联。被关联内容需先解除关联再删除，防止笔记附件被悄悄删掉。

PDF 默认复制到便携数据目录，并在后台提取可选文字；也可选择“关联本地 PDF”仅保存外部路径。详情“打开附件”使用系统默认阅读器，页码保存在关联列表中，默认阅读器不会自动跳页。外部路径失效可点击“重新定位”。扫描版 / 加密 PDF 不做自动 OCR 或解密。

## 快捷键与退出

| 默认快捷键 | 功能 |
| --- | --- |
| Ctrl+Alt+A | 区域截图，松开即自动保存和识别 |
| Ctrl+Alt+V | 快捷剪贴板面板 |
| Ctrl+Alt+F | 打开主窗口并搜索 |
| Ctrl+K | 当前主窗口内定位全局搜索 |
| Esc | 取消截图 / 关闭快捷面板 |

前三项可以在设置中自定义；支持 Ctrl / Alt / Shift / Win 加字母、数字或 F1–F24。Win+Shift+S 保留给 Windows。冲突会显示注册失败提示，修改设置时保留之前成功注册的快捷键。

默认关闭 / 最小化会隐藏到托盘。托盘菜单“完全退出”才结束进程；若系统没有托盘，则关闭窗口正常退出。同一便携目录不允许同时运行两份，启动第二份会显示提示。不同数据目录可以各自运行，但相同全局热键会发生冲突。

## 备份与迁移

在设置点击“备份 / 导出全部”。等待 OCR 完成再备份，备份期间暂停捕获；完成后恢复。恢复时先等待所有后台任务结束，再选择 ZIP。程序会校验数据库和附件、拒绝越界路径，并保留恢复前数据。

迁移便携软件时复制整个文件夹，或在另一份软件恢复备份。外部链接需重新定位，托管 PDF 和图片可以一起迁移。数据与备份没有加密，重要资料建议另存安全磁盘。
